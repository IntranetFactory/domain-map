# Relationship wording inventory

This file records what `.tmp_deploy/2026-11-03_relationship_wording_catalog.ts --apply` applies to the live catalog, with its data in `.tmp_deploy/2026-11-03_relationship_wording_catalog.json`. The script stores the old values in `backups/relationship-wording-2026-11-03.json` when it runs. The live rows were read on 2026-11-03 through the `semantius` CLI.

The owner decided to leave nothing: every relationship in the live catalog is called a relationship, including text and names. Every new text below was written by hand, one cell at a time.

- Inventory cells: 354 unique (363 listed before, 9 of them twice).
- Written by default: 331 cells.
- Written only with `--include-domain-data-objects`: 12 cells, because the future of `domain_data_objects` is undecided.
- Left unchanged, because they are not a relationship: 11 cells. See "Left unchanged".
- Computed labels refreshed: 17. See "Computed labels".
- Left out before this list was made, as not a relationship (web links, brands such as LinkedIn, network links, chain metaphors, `broken_link_findings`, integrations and physical connections): about 95 "link" cells, plus "connect" and "edge" cells of the same kinds.
- An em-dash in an old text is shown here as `--`, because the project forbids the character. Each one in a changed cell became a comma, colon or sentence break.
- Line breaks in a long text are shown here as a space.

**Outside these tables:** the validation rule on `data_object_relationships` is entity metadata, so it is not a row below. The live rule already has its new name, `users_relationship_is_not_many_to_many_reference`, and `.claude/skills/domain-map-analyst/SKILL.md` quotes that name.
